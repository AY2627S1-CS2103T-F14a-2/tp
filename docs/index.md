# Spotter

[![CI Status](https://github.com/AY2627S1-CS2103T-F14a-2/tp/actions/workflows/gradle.yml/badge.svg)](https://github.com/AY2627S1-CS2103T-F14a-2/tp/actions/workflows/gradle.yml)
[![codecov](https://codecov.io/gh/AY2627S1-CS2103T-F14a-2/tp/branch/master/graph/badge.svg)](https://codecov.io/gh/AY2627S1-CS2103T-F14a-2/tp)

**Every client, their next session and their progress, one command away.**

Spotter is a desktop app for freelance personal trainers to manage their clients, next sessions, body measurements
and gym performance. It is optimised for typing commands, so you can find a client and prepare for a session
without reaching for the mouse.

![Spotter showing a client list, a client's measurement and performance history, and the command box](images/Ui.png)

## Key features

* **Client records:** keep each client's name, phone, email and tags, and find clients by name or tag.
* **Next sessions:** book or cancel a client's next session, and list the sessions on any date.
* **Upcoming sessions:** see upcoming booked sessions, soonest first, with each client's latest progress.
* **Body measurements:** record weight, body fat and waist measurements over time.
* **Gym performance:** record exercises with sets, reps and load.
* **Client history:** open one client's full measurement and performance history before a session.
